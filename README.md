# Bdjobs Invitations - Playwright Automation

This project contains automated test scripts for the Invitations module of Bdjobs using Playwright with Python.

## Automated Test Scenarios

### General Interview
- Verify General Interview invitation flow
- Validate invitation-related actions and navigation

### Video Interview
- Verify Video Interview invitation flow
- Validate Video Interview invitation flow and navigation
